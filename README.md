Simple Calculator 🧮

About

This is my first Python project. It is a simple calculator that performs basic arithmetic operations.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Accepts user input

Technologies Used

- Python
- Visual Studio Code

How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

python calculator.py

What I Learned

- Python variables and user input
- Conditional statements ("if", "elif", "else")
- Arithmetic operators
- Basic error handling
